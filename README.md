# StepShot Web（β版）

デスクトップ版（PySide6）と同じレイアウト計算・グリッド合成ロジックをブラウザに
移植した、単一HTMLファイルのWeb版。サーバー不要、ブラウザだけで完結する。

**現在ベータ版として公開中です。** ご意見・不具合報告はアプリ内の「💬 フィードバック」リンクからお願いします。

## 使い方

方法はどちらでもOK。

### 方法A: ファイルを直接開く（一番手軽）

`index.html` をダブルクリックしてブラウザで開くだけ。

### 方法B: ローカルサーバー経由で開く（推奨）

一部のブラウザ設定によっては `file://` で開くとIndexedDBの動作が制限される
場合があるため、気になる場合はこちらを使う。

```bash
cd StepShot-Web
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開く。

## できること（デスクトップ版と同じ機能）

- ヘッダー右上の「❓ ヘルプ」から、スクリーンショット付きの使い方ガイド（`help.html`）を開ける

- プロジェクト作成・一覧・設定編集・削除
- レイアウト設定: 縦一列 / 列数指定 / 自動調整
- 出力最大幅のプリセット選択（画面解像度、note/Instagram/X/YouTube/Facebookサイズ）
- 画像追加: クリックでのファイル選択、ドラッグ&ドロップの両対応
- ステップのドラッグ&ドロップによる並び替え
- 説明文編集（複数行・リアルタイム文字数表示、3行を超える場合は自動で省略記号）
- レターボックス方式によるアスペクト比保持（クロップなし）
- プレビュー表示（実寸・スクロールで確認）、PNG書き出し（ブラウザのダウンロード機能）
- Google Driveをブラウザで開いての手動アップロード案内

## デスクトップ版との違い

| | デスクトップ版 | Web版 |
|---|---|---|
| データの保存場所 | SQLite（ファイルとして手元に残る） | ブラウザのIndexedDB（サイトデータ削除で消える） |
| 画像の保存 | プロジェクトフォルダにコピー | IndexedDBにBlobとして保存 |
| PNG書き出し | 保存先を選ぶダイアログ | ブラウザの標準ダウンロード（通常はダウンロードフォルダに保存） |
| Google Drive連携 | ブラウザ起動＋フォルダを開く | ブラウザの新規タブを開く（同一ブラウザ内なので、むしろこちらの方が楽） |

## 動作確認済み

Playwright（Chromium）で以下を自動テスト済み:

- プロジェクト作成・一覧表示
- 画像の複数追加
- 説明文編集・文字数表示
- プレビュー生成（Canvasサイズがデスクトップ版のPython計算結果と一致することを確認）
- PNG書き出し（実際にダウンロードされることを確認）
- ステップの並び替え（IDベースで順序が正しく入れ替わることを確認）
- ステップ削除・プロジェクト設定編集・プロジェクト削除
- プロジェクト未選択時の警告メッセージ
